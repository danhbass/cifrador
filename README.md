# Cifrador — versão 1.0.4

Pacote da aplicação PWA com página pública de apresentação, aplicação web e demonstração interativa.

## Novidade desta versão

- A barra superior aparece exclusivamente quando a aplicação é aberta em modo Demo (`?demo=1`).
- O atalho **Voltar para tela de apresentação** retorna à página pública.
- O atalho **Instalar Cifrador no celular** utiliza a instalação nativa quando o navegador oferece suporte e, nos demais casos, mostra instruções adequadas ao dispositivo.
- A aplicação definitiva continua sem essa barra.

## Publicação

Publique o conteúdo da pasta `cifrador-main` mantendo a estrutura de diretórios. A página pública fica em `index.html`; a aplicação web fica em `app/`; a demonstração pode ser acessada por `demo/`.

Consulte `version.json` e `version-history.json` para a versão e o histórico de alterações.
